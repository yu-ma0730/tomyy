ファンダメンタル分析

経済指標と政治的要因から通貨の本来の価値を分析

ファンダメンタル分析とは

ファンダメンタル分析は、経済指標、金利、地政学的リスク、商品価格など、国の経済状況を総合的に分析して、通貨の本来の価値（フェアバリュー）を判定する手法です。中・長期のトレンド形成に大きな影響を与えます。

主要経済指標

GDP（国内総生産）

  • 概要: 国全体の経済規模を示す最重要指標
  • 発表頻度: 四半期ごと（速報値・改定値・確定値）
  • 影響: GDPが高い ⟹ その国の通貨は強くなる傾向
  • 注目: 予想値との乖離が大きいとボラティリティ上昇

雇用統計

失業率と非農業部門雇用者数

  • 概要: 労働市場の健全性を示す指標
  • 発表頻度: 毎月（米国の場合は毎月第一金曜日）
  • 失業率低下: ポジティブシグナル（通貨強気）
  • 注目度: FX市場で最も影響力の大きい指標の一つ

インフレーション指標

CPI（消費者物価指数）

  • 概要: 商品やサービスの価格変動を測定
  • 高インフレーション: 中央銀行が金利引き上げの可能性
  • 低インフレーション: 金利引き下げ、金融緩和の可能性
  • 市場への影響: 金利見通しを通じて通貨に大きく影響

金利（政策金利）

中央銀行の基本政策金利

  • 概要: 中央銀行が設定する最重要な政策金利
  • 高金利: その通貨への投資需要が増加（通貨高）
  • 低金利: その通貨からの逃避（通貨安）
  • 注目: 金利差がキャリートレードの動機に

小売売上高

消費者支出を示す指標

  • 概要: 小売業での売上を月ごとに集計
  • 発表頻度: 毎月（米国は毎月中旬）
  • 売上増加: 経済が好調なシグナル
  • 売上減少: 経済減速・景気悪化の懸念

製造業PMI

Purchasing Managers Index

  • 概要: 製造業の景気指数（50が分岐点）
  • 発表頻度: 毎月
  • 50以上: 製造業が拡大
  • 50以下: 製造業が縮小

その他の重要な経済要因

貿易収支

定義: 輸出額から輸入額を差し引いた数値

  • 黒字が大きい → その国の通貨が強くなる傾向
  • 赤字が続く → 通貨の弱体化の可能性
  • 貿易依存国にとっては特に重要な指標

通貨供給量（マネーサプライ）

定義: 市場に流通している通貨の総量

  • 供給量増加 → インフレの懸念（金利上昇可能性）
  • 供給量減少 → デフレリスク（金利低下可能性）
  • 中央銀行の金融政策の意図を読み取る重要指標

地政学的リスク

定義: 政治的・軍事的紛争が経済に与える影響

  • 戦争やテロ → リスクオフ（セーフハーバー通貨へ資金流入）
  • 国交問題 → その国の通貨に悪影響
  • 選挙や政治的不安定性 → 通貨ボラティリティ上昇

商品価格

定義: 原油、金、穀物などのコモディティの価格

  • 原油価格 → カナダドルやノルウェークローネに影響
  • 金価格 → USD（ドル）と逆相関
  • 資源国通貨の動きに大きな影響

ファンダメンタル分析を使った取引戦略

金利差アプローチ

各国の金利政策を分析し、金利差が拡大している通貨ペアへの投資。キャリートレードの基本戦略。

経済成長率の比較

複数国のGDP成長率を比較し、成長が加速している国の通貨を買い、減速している国の通貨を売る。

インフレーション・トレード

インフレーション率の高い国と低い国の通貨ペアを狙う。インフレが高まると金利引き上げ期待で通貨が上昇。

リスクオン・リスクオフ戦略

地政学的リスクの高まり時にはセーフハーバー通貨（USD、CHF、JPY）を買い、リスク回避。

中央銀行ウォッチング

中央銀行のコメント、金融政策決定会合をリアルタイムで監視し、政策変更の兆候を早期に察知。

経済カレンダーの活用

ファンダメンタル分析を実践するには、重要な経済指標の発表予定を常に把握しておくことが重要です。以下のようなリソースを活用します：

指標の重要度を確認

経済カレンダーには指標の重要度が★で表示されます。★★★は特に高インパクト。

前月との比較

前月結果と当月予想値の差を確認。市場の期待度を把握。

タイムゾーン確認

各国の指標発表時間に注意。米国指標の発表時はボラティリティが高まる。

サプライズの影響

予想値との大きな乖離（サプライズ）は相場を大きく動かす。

テクニカル分析との使い分け

項目 ファンダメンタル分析 テクニカル分析
分析対象 経済指標・政策 価格・出来高
時間軸 中・長期（数週間～数年） 短期～中期（数時間～数週間）
主な用途 大きなトレンド把握 エントリー・エグジットの精密化
難易度 複雑（多くの要因） 習得しやすい
取引頻度 少ない（ポジション長期保有） 多い（頻繁な取引）
