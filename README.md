# FX分析ナビ

FXトレードに必要な分析手法を学べる総合サイトです。

## 概要

このサイトは、FX（外国為替）取引を学ぶ人向けに、以下の2つの主要な分析手法を詳しく解説しています：

- **テクニカル分析**: 過去の価格変動パターンから市場の方向性を予測
- **ファンダメンタル分析**: 経済指標や政治的要因から通貨の本来の価値を分析

## ページ構成

### 1. ホームページ (index.html)
- サイトの概要説明
- テクニカル分析とファンダメンタル分析の特徴比較
- 両分析手法が必要な理由の解説

### 2. テクニカル分析ページ (technical.html)
- **チャートパターン**: ヘッドアンドショルダーズ、ダブルトップ、トライアングルなど
- **移動平均線（MA）**: SMA、EMA、WMAの説明
- **RSI**: 買われすぎ・売られすぎの判定指標
- **MACD**: トレンド転換の判定
- **ボリンジャーバンド**: ボラティリティの分析
- **サポート・レジスタンス**: 重要な価格水準
- **取引戦略**: トレンドフォロー、オシレーター戦略など
- **テクニカル分析のコツ**: 実践的なアドバイス

### 3. ファンダメンタル分析ページ (fundamental.html)
- **主要経済指標**:
  - GDP（国内総生産）
  - 雇用統計（失業率、非農業部門雇用者数）
  - インフレーション指標（CPI）
  - 金利（政策金利）
  - 小売売上高
  - 製造業PMI
- **その他の経済要因**: 貿易収支、マネーサプライ、地政学的リスク、商品価格
- **取引戦略**: 金利差アプローチ、経済成長率比較など
- **経済カレンダーの活用**: 重要指標の発表予定の確認方法
- **テクニカル分析との比較表**: 両分析手法の特徴比較

## 特徴

- **レスポンシブデザイン**: スマートフォンやタブレットでも見やすい
- **わかりやすい構成**: カード形式とグリッドレイアウトで情報を整理
- **実践的な内容**: 実際のトレードに役立つ情報を掲載
- **視覚的な表現**: 色分けと図表を使って理解しやすく
- **スムーズなナビゲーション**: スティッキーナビゲーションで常時アクセス可能
