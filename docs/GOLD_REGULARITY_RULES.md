# ゴール規則性手法 - シグナルツール解説

## 概要
このツールは、ゴール（GOLD/金）の15分足チャートでEMA（指数移動平均線）の規則性パターンを検出し、トレーディングシグナルを提供します。

**精度**: 体感70～80%程度（100%ではありません）

---

## 基本設定

- **時間足**: 15分足（PERIOD_CURRENT に設定）
- **使用インジケーター**: EMA 10, 20, 40, 80
- **プラットフォーム対応**:
  - MT5（MQL5 スクリプト）
  - TradingView（PineScript v5）

---

## 3つの規則性ルール

### ✅ Rule #1: EMAに上から順番にタッチを続けていく

**上昇トレンド時の完全オーダー（Perfect Order）:**
```
Price > EMA10 > EMA20 > EMA40 > EMA80
```

価格がEMA10から順にEMA20、EMA40、EMA80へと上からタッチしていく状態。このパターンが形成されると、上昇トレンドの継続を示します。

**検出方法**:
- チャートの完全オーダーが形成されているか確認
- 下降トレンドでは逆順になります

---

### ✅ Rule #2: EMAを下抜けた場合には次の下のEMAをタッチしに向かう

**ショートシグナル（SHORT Signal）:**

1. **EMA10 下抜け**
   - 価格がEMA10を下抜ける（Close < EMA10）
   - その後、通常はEMA20までの下落が高確率
   - このタイミングで最初のショートエントリーシグナル

2. **EMA20 下抜け**
   - EMA10下抜けの後、価格がEMA20も下抜ける
   - 次はEMA40を目指す傾向

3. **目標設定**
   - EMA10下抜け → EMA20が目標（最初の目標）
   - EMA20下抜け → EMA40が目標
   - 最終的には EMA80 での反発で下落終了

**注意点**: 「騙しパターン」が存在
- 抜けたと思ったら反発する場合あり
- EMA10下抜け直後のエントリーは避ける
- 下落が続くことを確認してからエントリーを推奨

---

### ✅ Rule #3: EMA20のみは複数回反発する傾向が高い

**EMA20の特性:**

EMA20は他のEMA（10, 40, 80）と比べて、**複数回反発する傾向**が高い。

- 下降トレンド中に何度もEMA20で反発
- EMA20がサポート/レジスタンスとして機能しやすい
- 反発が続く場合がある（含み損が長くなる可能性）

**対応方法**:
1. **メンタル準備**: EMA20で反発しても耐える
2. **ロット調整**: 損切までの距離を考慮したロット管理
3. **損切の判断**: ロスカット水準をあらかじめ決める

## エントリータイミング

### ショート（SHORT）エントリー

**基本的なエントリータイミング**: EMA下抜けのタイミング

```
推奨フロー:
1. EMA10下抜けを確認 → アラート発生
2. 価格が一時的に戻るのを待つ
3. 再度下落開始を確認
4. エントリー実行
5. 目標: EMA20 または EMA40
```

**重要**: 抜けてすぐにエントリーしない
- 騙しパターンの回避
- 下落の勢いを確認してからエントリー
- 値動きが強烈な場合は例外

### ロング（LONG）エントリー

**リバウンド・ロング**:
- EMA20でのバウンスを狙う
- 最終反発地点（EMA80）でのロング

**押し目買い**:
- 上昇トレンド中の一時下落（EMA10タッチ）で買い
- 目標: 1つ上のEMA

---

## 利確（テイクプロフィット）戦略

### ショートの場合
- **第1目標**: EMA20
- **第2目標**: EMA40
- **最終目標**: EMA80 での反発（下落終了）

### ロングの場合
- **通常**: 1つ上のEMAまで
- **EMA80からの上昇**: 週足高値などの上昇トレンドを目指す

---

## 最終的な終了信号

### 下落フェーズの終了
- **EMA80への反発** → 下落終了の高確率シグナル
- EMA80で何度も反発する傾向
- SMA50も終了タイミングの指標になる場合あり

### トレンド転換の確認
下降の完全オーダーから上昇の完全オーダーへの切り替わり:
```
下降: Price < EMA10 < EMA20 < EMA40 < EMA80
     ↓
上昇: Price > EMA10 > EMA20 > EMA40 > EMA80
```
この切り替わりはトレンド転換を示唆

## 注意点とリスク管理

### ⚠️ 重要な注意点

1. **完全ではない**
   - 精度は70～80%程度
   - 100%確実ではない

2. **騙しパターン**
   - EMA下抜け → 反発する場合あり
   - EMAとの価格がピッタリ重なる場合あり
   - 対応: 下落の継続確認後にエントリー

3. **含み損が長くなる場合**
   - EMA20の複数回反発
   - 上昇によるロスカット回避が重要

### 🛡️ リスク管理

1. **ロット調整**
   - EMA20への反発距離を考慮
   - ロスカット水準までの距離を計算
   - ロット数を減らす選択肢も検討

2. **メンタル準備**
   - 含み損期間を耐える
   - あらかじめ想定される値動きを理解

3. **損切の判断**
   - ロスカット水準をあらかじめ決定
   - 損切タイミングの基準を明確にする

4. **一度の利確後の再エントリー**
   - EMA20に達して利確したローソク足は
   - 再度のエントリー判断には使えない
   - 新しいシグナルまで待つ

   - 自分のルール適用が正しいか確認

## ツール設定ガイド

### TradingView 設定
```
- Enable Alerts: ON/OFF（アラート有効化）
- Enable Notifications: ON/OFF（通知有効化）
- 色設定: 自由にカスタマイズ可能
```

### MT5 設定
```
- EnableAlerts: true/false
- EnableNotifications: true/false
- SignalSize: 矢印のサイズ
- UpSignalColor: 上昇シグナルの色
- DownSignalColor: 下降シグナルの色
```
