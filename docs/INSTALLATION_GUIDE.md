# インストール・使用ガイド

## TradingView での導入方法

### ステップ1: TradingViewへアクセス
1. [TradingView](https://tradingview.com) にログイン
2. チャートを開く（GOLD, 15分足）

### ステップ2: インジケーターを追加
1. チャートの上部 `インジケーター` ボタンをクリック
2. 右上の検索バーで「GoldRuleSignalTool」を検索
   - または `+新規スクリプト` から手動追加

### ステップ3: スクリプトを追加（手動の場合）
1. `+ ボタン` → `スクリプト作成`
2. 下のコードをコピー:
   ```
   /tradingview/GoldRuleSignalTool.pine
   ```
3. スクリプトエディタに貼り付け
4. `保存して追加`

### ステップ4: 設定を調整
インジケーターパネルで以下を設定：
- **Enable Alerts**: `true` (オン)
- **Enable Notifications**: 任意（推奨: false）
- **UP Signal Color**: 緑系
- **DOWN Signal Color**: 赤系
- **Signal Arrow Size**: 2 推奨

### ステップ5: アラート設定（重要）
1. チャートの右上時計マーク → `アラート`
2. 「GoldRuleSignalTool」を選択
3. 通知方法を選択（メール、SMS、ブラウザ等）
4. `作成` クリック

## MT5 での導入方法

### ステップ1: MetaEditor を開く
1. MT5 を起動
2. `ツール` メニュー → `MetaEditor`
   （またはキーボード `Ctrl+Shift+E`）

### ステップ2: 新規ファイルを作成
1. `ファイル` → `新規`
2. ファイルタイプ: `インジケーター`
3. ファイル名: `GoldRuleSignalTool`
4. `次へ` → `完了`

### ステップ3: コードをコピー
1. 下のファイルを開く:
   ```
   /mt5/GoldRuleSignalTool.mq5
   ```
2. すべてのコードをコピー
3. MetaEditor のスクリプトエリアに貼り付け

### ステップ4: コンパイル
1. `F5` キーを押すか、メニューから `コンパイル`
2. `Output` タブにエラーがないか確認
   - 警告は無視しても問題ありません

### ステップ5: チャートに追加
1. MT5 のメインウィンドウに戻る
2. GOLD 15分足チャートを開く
3. `挿入` メニュー → `インジケーター` → `カスタム`
4. `GoldRuleSignalTool` を選択
5. `OK`

### ステップ6: パラメータ設定
インジケーターのパラメータウィンドウで以下を設定：
- **EnableAlerts**: `true`（アラート有効）
- **EnableNotifications**: `false`（任意）
- **UpSignalColor**: `Green` (緑)
- **DownSignalColor**: `Red` (赤)
- **SignalSize**: `2`

## 動作確認

### 正常に動作しているサイン
✅ チャートに矢印が表示される
✅ EMA10, 20, 40, 80 が表示されている
✅ 価格が EMA を下抜けると下向き矢印が出現
✅ アラートが音または通知で来る

### トラブルシューティング

#### TradingView の場合

**症状**: インジケーターが表示されない
```
対応:
1. ページをリロード（F5）
2. ブラウザキャッシュをクリア
3. 別のブラウザで試す
```

**症状**: アラートが来ない
```
対応:
1. インジケーター設定でアラートが有効か確認
2. TradingView アラート設定を確認
3. ブラウザの通知許可を確認
```

**症状**: 矢印がおかしな位置に出ている
```
対応:
1. EMA10, 20, 40, 80 が正しく表示されているか確認
2. チャート時間足が15分足か確認（重要）
3. ズーム調整（Ctrl + マウスホイール）
```

---

#### MT5 の場合

**症状**: コンパイルエラーが出ている
```
対応:
1. MQL5 バージョンの確認（v5 以上が必要）
2. スペースやタブの修正
3. ファイルを新規作成してコードを貼り直す
```

**症状**: チャートに表示されない
```
対応:
1. MetaEditor で正常にコンパイルされているか確認
2. チャートが GOLD, 15分足か確認
3. インジケーター一覧を更新: Ctrl+Shift+I
4. MT5 を再起動
```

**症状**: アラームが出ない
```
対応:
1. EnableAlerts が true か確認
2. MT5 の音声アラート設定を確認
   ツール → オプション → イベント → 通知
3. ボリュームが0になっていないか確認
```

## 初期テスト

### チェックリスト
```
□ チャートに3本以上の矢印が表示されている
□ EMA の順序が正しい（上昇なら: Price > EMA10 > EMA20 > EMA40 > EMA80）
□ 15分足チャートを使用している
□ アラート音が出ている（アラート有効時）
□ 過去のシグナルが実際のチャートと一致している
```

### 推奨される検証方法
1. **過去チャートの確認** (バーをドラッグ)
   - 過去1週間分のシグナルを確認
   - 実際の値動きとシグナルが一致しているか確認

2. **ルール理解の確認**
   - 各矢印が Rule#1, #2, #3 のどれに基づいているか確認
   - アラートメッセージの内容を理解

3. **デモトレードの実施**
   - 3～5シグナル分 をデモで実行
   - 勝ったシグナル、負けたシグナルを分析

## よくある質問

**Q: EMA が表示されていません**
A: 
- TradingView: 指標を手動で追加してください
- MT5: EMA を別途インジケーターとして追加してください

**Q: 矢印が出ません**
A: 
- チャート時間足が 15分足 か確認
- ページ/MT5 を再読み込みしてください
- スクリプトが正常に動作しているか確認

**Q: シグナルが多すぎます**
A: 
- 完全ではないツールのため、すべてのシグナルに従わない
- エントリー前に必ず Rule #2（下落確認）を待つ

**Q: シグナルが少なすぎます**
A: 
- 市場環境により信号数は変わります
- 相場が完全オーダー形成中は信号が減少
