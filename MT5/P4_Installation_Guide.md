# P4 Signal Tool - MT5 インストール・使用ガイド

## 概要
P4手法は、完全注文（Perfect Order）のEMAを用いた15分足トレンド順張り戦略です。MT5での実装により、シグナル自動検出と取引管理が可能になります。

## ファイル構成

### 1. インジケーター
- **`Indicators/P4_Signal_Tool.mq5`**
  - EMA（10, 20, 40, 80）の表示
  - ボリンジャーバンド表示
  - パーフェクトオーダー判定
  - エントリーシグナル表示

### 2. Expert Advisor (EA)
- **`Experts/P4_TradeManager.mq5`**
  - 自動取引管理
  - 損切・利確の自動設定
  - ボリンジャーバンドフィルター
  - N字パターン認識（オプション）

## インストール方法

### ステップ1: ファイルコピー
1. MT5を開く
2. メニューから「ファイル」→「データフォルダを開く」
3. `MQL5/Indicators/` フォルダに `P4_Signal_Tool.mq5` をコピー
4. `MQL5/Experts/` フォルダに `P4_TradeManager.mq5` をコピー

### ステップ2: コンパイル
1. MT5のナビゲーターで「エキスパートアドバイザー」を右クリック
2. 「更新」をクリック
3. 新しいEAが表示されることを確認

### ステップ3: インジケーター設定
1. チャートに15分足でログイン
2. 「ナビゲーター」→「インジケーター」から「P4_Signal_Tool」をドラッグ
3. 設定画面が表示されたら「OK」をクリック

## パラメータ設定

### インジケーター設定 (P4_Signal_Tool.mq5)

| パラメータ | デフォルト | 説明 |
|-----------|----------|------|
| EMA10_Period | 10 | EMA10の期間 |
| EMA20_Period | 20 | EMA20の期間 |
| EMA40_Period | 40 | EMA40の期間 |
| EMA80_Period | 80 | EMA80の期間 |
| BB_Period | 20 | ボリンジャーバンドの期間 |
| BB_Deviation | 2.0 | ボリンジャーバンドの標準偏差 |
| Lookback_Bars | 5 | ウィック判定期間 |
| Show_PerfectOrder_Info | true | PO情報表示 |
| Use_BB_Filter | true | BBフィルター有効 |

### EA設定 (P4_TradeManager.mq5)

| パラメータ | デフォルト | 説明 |
|-----------|----------|------|
| Magic | 12345 | マジックナンバー |
| LotSize | 0.1 | 取引ロット数 |
| AutoTrading | false | 自動取引有効 |
| RiskRewardRatio | 1.0 | リスク・リワード比 |
| Use_BB_Filter | true | BBフィルター有効 |
| Extend_Profit_on_N_Pattern | true | N字での利幅拡張 |

## 使用方法

### 1. インジケーター表示のみ（推奨・手動取引）
```
1. P4_Signal_Tool インジケーターをチャートに追加
2. 画面上に表示されるシグナルを確認
3. 自分のルール通りエントリー・決済
```

**シグナル表示:**
- 🟢 **緑の矢印** = ロングエントリー推奨
- 🔴 **赤の矢印** = ショートエントリー推奨
- 🟦 **青いヒストグラム** = パーフェクトオーダー継続中

### 2. 自動取引（EAを使用）
```
1. チャートにP4_TradeManagerを添付
2. 「自動取引を有効化」をクリック
3. 「エキスパートアドバイザーを許可」の確認ダイアログで「OK」
4. パラメータを調整
5. 取引自動実行
```

## エントリーシグナルの判定基準

### ロング（買い）エントリー条件
✅ **必須条件:**
- EMA順序: EMA10 > EMA20 > EMA40 > EMA80 (上から順)
- 価格がウィック抵抗線を上抜け

⚠️ **BBフィルター有効時:**
- 価格がボリンジャーバンド上限から大きく出ていない
  - 出ていた場合: エントリー見送り（25%）またはロット縮小（75%）

### ショート（売り）エントリー条件
✅ **必須条件:**
- EMA順序: EMA80 > EMA40 > EMA20 > EMA10 (上から順)
- 価格がウィックサポート線を下抜け

⚠️ **BBフィルター有効時:**
- 価格がボリンジャーバンド下限から大きく出ていない
  - 出ていた場合: エントリー見送り（25%）またはロット縮小（75%）

## 損切・利確の設定

### 損切位置
- **ロング**: エントリーラインの直近最安値
- **ショート**: エントリーラインの直近最高値

### 利確位置（基本）
```
利確位置 = エントリー + (リスク × リスク・リワード比)

例:
- エントリー: 1.0900
- 損切: 1.0850 (リスク: 50pips)
- リスク・リワード比: 1:1
- 利確: 1.0950 (リスク・リワード: 1:1)
```

### 利幅拡張方法

#### 方法①: N字パターン認識
```
条件: 利確到達後、N字チャート形成を確認
- 最初のN字の上昇率を測定
- N字最後も同等分上昇すると予想
- 利確を延長
```

#### 方法②: EMA80タッチ
```
条件: 相場がEMA80にタッチ
- EMA80到達まで利確を延長
- リスク: 反転可能性
- 推奨: 基本利確が推奨（確実性重視）
```

## ⚠️ 重要な注意事項

### 1. パーフェクトオーダー崩れ = 強制決済
```
含み益・含み損に関わらず、PO崩れで即決済
- PO判定: EMA順序が変わったら終了
- 次のPO形成まで待つ
```

### 2. 時間足の制限
```
⛔ このシステムは15分足専用です
- 他の時間足では使用禁止
- 複数通貨ペアで並行取引可能
```

### 3. エントリー構成（BBフィルター有効時）
```
例: チャンス8回
- 75%: 6回エントリー（正常エントリー）
- 25%: 2回見送り（BBカット）

75:25の比率で期待値が最適化
```

### 4. 連続エントリー（PO継続中）
```
PO継続中は何度もエントリー機会が来ます
- 基本利確で毎回決済
- 再度PO形成待機
- 平均して利益を積み上げ
```

## トレーニングモード（初心者向け）

```
Step1: インジケーター表示のみで練習
- 1-2週間、シグナル確認のみ
- 実際のエントリーは行わない
- パターン認識の習得

Step2: 小ロット手動取引
- リアルマネー0.01ロット以下
- エントリー・決済を手動実行
- 1-4週間、トレード経験蓄積

Step3: 自動取引開始
- パラメータを検証済みで設定
- 0.1ロットからスタート
- 2-4週間のバックテスト結果確認後
```

## トラブルシューティング

### インジケーターが表示されない
```
✓ 15分足チャートを開いているか確認
✓ インジケーター再読込: Ctrl + R
✓ コンパイルエラーをログで確認
```

### EAが取引しない
```
✓ 自動取引が有効か確認
✓ ポジション制限数を確認
✓ アカウントのレバレッジを確認
✓ 証拠金が十分か確認
```

### パーフェクトオーダーが検出されない
```
✓ EMA期間の設定を確認 (10, 20, 40, 80)
✓ 十分なバーデータ (最低100本)
✓ 相場環境がレンジ相場でないか確認
  → PO形成には強いトレンドが必要
```

## 推奨取引条件

- **通貨ペア**: EURUSD, GBPUSD, USDJPY
- **時間足**: 15分足のみ
- **相場環境**: トレンド相場（確認: 日足の方向性確認）
- **取引時間**: ロンドン～ニューヨーク時間
- **スプレッド**: 2pips以下が目安
