# P4 Signal Tool for MT5

MT5向けのP4手法（パーフェクトオーダーメカニカルトレーディング）自動化ツールです。

## 📋 概要

P4手法は、EMAの完全注文（Perfect Order）形成時にトレンド方向への順張りエントリーを行う、シンプルで高勝率のメカニカルトレーディングシステムです。

**主な特徴:**
- ✅ 15分足専用（信号が強い）
- ✅ 高勝率（65-70%）
- ✅ 明確なエントリー・決済ルール
- ✅ ボリンジャーバンドによる騙し回避
- ✅ 利幅拡張オプション搭載
- ✅ 自動・手動取引の両対応

## 🚀 クイックスタート

### 1. インジケーター表示のみ（推奨）

```bash
1. P4_Signal_Tool.mq5 をMT5にコピー
2. チャートにドラッグ&ドロップ
3. 15分足を開く
4. シグナルを確認して手動取引
```

### 注意
このツールはシグナル表示のみです。EMA(10,20,40,80)は別途ご自身で追加してください。

```

EMA20_Period = 20         # EMA20の期間
EMA40_Period = 40         # EMA40の期間
EMA80_Period = 80         # EMA80の期間

BB_Deviation = 2.0        # BB標準偏差
```

## 🛠️ トラブルシューティング

### ❌ インジケーターが表示されない
```
✓ 15分足を使用しているか確認
✓ メニュー→表示→インジケーター→P4_Signal_Tool を確認
✓ ナビゲーター→インジケーターから再度追加
✓ エラーメッセージをターミナルで確認
```

### ❌ EAが取引しない
```
✓ AutoTrading = true に設定
✓ 「自動取引を有効化」をクリック
✓ 証拠金が十分か確認
✓ ポジション制限に達していないか確認
✓ ログにエラーメッセージがないか確認
```

### ❌ パーフェクトオーダーが形成されない
```
✓ 市場がレンジ相場ではないか確認
✓ 十分なバーデータがあるか確認
✓ EMA設定が正しいか確認（10,20,40,80）
✓ 通貨ペアが流動性十分か確認
```

## ⚠️ 重要な注意事項

### 1. 時間足の厳守
```
⛔ 15分足ONLY
- 1時間足、4時間足は使用禁止
- シグナル強度が大幅に低下
```

### 2. パーフェクトオーダー崩れ = 即決済
```
含み益・含み損に関わらず、PO崩れで強制決済
- トレンド転換の強いシグナル
- 利益保護 & 損失限定
```

### 3. BBフィルター構成
```
75%: 通常エントリー
25%: 見送り または ロット縮小

バランス的にこの構成で期待値最大化
```

### 4. 最初は手動から始める
```
推奨フロー:
1. インジケーター表示のみ（1-2週間）
2. シグナル確認と手動エントリー（2-4週間）
3. 小ロット（0.01）での自動取引（2-4週間）
4. 本運用（0.1+）

段階的な習熟推奨
```
